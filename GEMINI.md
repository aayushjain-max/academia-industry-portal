# Workspace Instructions & Skills Guidelines

## Skill & Knowledge Repositories Activation
- Always inspect the available skills and repository guidelines registered in the environment (e.g., in ~/.gemini/config/skills/, ~/.gemini/config/plugins/, or .agents/rules/).
- For any user prompt, actively match relevant skills (such as frontend UI engineering, design taste, API design, testing, database best practices, or research plugins) and consult their SKILL.md instructions before executing tasks.
- Adhere strictly to the best practices defined within those skill repositories across all code generation, refactoring, and project architecture workflows.
