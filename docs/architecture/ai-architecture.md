# AI Service Architecture (FastAPI)

Decoupled Python microservice dedicated to computational intelligence:
- **Skill Profiling Pipeline**: Assessment results normalization and scoring.
- **Skill Gap & Action Plan Generator**: Deterministic & LLM-assisted progression paths.
- **JD Analyzer**: Parsing unstructured job descriptions into structured skill taxonomies.
- **Opportunity Matching Engine**: Multi-factor scoring (Skills 50%, Experience 20%, Domain 15%, Location 15%).
- **RAG Career Assistant**: Semantic question answering grounded in student profile data.
